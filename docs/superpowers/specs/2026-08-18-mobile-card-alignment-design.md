# 移动端笔记与待办卡片对齐设计

## 目标

改善移动端卡片的信息层级和横向对齐，不改变数据、交互语义及桌面端布局。

## 笔记卡片

- “引用 X 条笔记，被 Y 条笔记引用”摘要字号降低一级。
- 摘要的展开图标与文字使用同一 flex 行，垂直居中；图标固定尺寸并禁止收缩。
- Chat 与引用按钮保留当前功能和触控尺寸，但在移动端使用紧凑横向操作组，缩小两者的视觉间距。
- 桌面端现有 hover、菜单和按钮位置保持不变。

## 待办卡片

- 有子任务时，展开/收起图标从左侧内容起始区移到卡片右侧操作区。
- 左侧只保留复选框和正文，使所有待办的文字起始位置一致。
- 图标仍使用现有展开状态和无障碍文案，不改变子任务树逻辑。
- 移动端保留至少 44px 的可触控区域；桌面端维持紧凑尺寸。

## 验收

- 移动端引用摘要明显小于笔记正文，图标与文字基线协调。
- Chat 与引用图标彼此靠近，无大块空白。
- 有无子任务的待办正文左边缘一致，折叠图标位于右侧。
- 格式检查、类型检查及相关组件测试通过；若仓库已有无关类型错误，单独记录。
